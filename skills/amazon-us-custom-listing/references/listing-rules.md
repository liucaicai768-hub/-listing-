# 原始表格规则及处理说明

来源：用户提供的 `listing规范输出.xlsx`，工作表 `标题5点SOP (2)`。此文件是整理记录，不是实时平台政策验证结果。

| 字段 | 表格长度建议 | 主要要求 |
| --- | --- | --- |
| Item Name | 75 字符内，权重最大 | 核心、高权重、高相关关键词优先；兼顾可读性和搜索相关性；不要全大写，介词小写；原文“禁止重复词超2词” |
| Item Highlight | 125 字符内，有搜索权重 | 功能或利益短语，非完整句子；只有名称少于 75 字符时展示；不重复名称信息；不要全大写，介词小写；原文“禁止重复词超2词” |
| Bullet Point | 每点适合手机阅读的 2 行 | 针对具体特点；嵌入用户提供的出单关键词；平台字段说明禁止全大写和缩写，不用于面料成分、护理说明或产地；另一列要求“五点的标题大写” |
| Product Description | 未指定 | 段落形式；真实的独特特点、产品线信息和产品规格；不全大写 |
| Generic Keyword | 建议 250 bytes 内 | 相关搜索词、小写、不重复、不重复标题词、不含竞品品牌或 ASIN |

禁止包含主观评价类词组，例：Perfect Gift、Best Gift、Anniversary Gift、Great Gift、Baby Shower Gift。规则禁止的是组合，单个词可以用。

提交前检查：标题合规、五点不重复、描述真实、搜索词去重并核对 bytes。

## 操作解释

- 对标题的“75 字符内”采用 ≤75；若输出商品亮点，采用 <75，默认 ≤74。
- “五点的标题大写”与“不全大写”冲突，采用短标题首字母大写（Title Case），保留可读性。若用户要求全大写，应指出原始规则冲突。
- “禁止重复词超2词”含义不够明确，默认同一单词不得出现超过两次，标题和亮点分别计算。这是操作解释，不冒充表格明确给出的计数方法。
- 五点手机两行没有确定字符阈值，靠简洁写作和实际展示复核。
- 250 bytes 按 UTF-8 计算。字符数不等于字节数。
- 表格未规定描述长度、HTML 格式或具体商品类别的特殊政策，不虚构这些限制。
