# 项目输入卡

- 站点 / 语言 / 币种：
- 产品名称 / ASIN：
- 核心产品形态：
- 主要功能与参数（材质、尺寸、功率、颜色等）：
- 明确不具备的功能：
- 核心消费者 / 使用场景：
- 直接竞品 ASIN：
- 关键词源文件 / 工作表 / 数据周期：
- 允许扩展的关键词范围：
- 直接排除的产品形态：
- 本次用途（Listing / 广告 / 预算分析 / 排名跟踪）：
- 需要保留的指标与定义：
- 同口径数据冲突时的来源优先级：
- 分类或优先级阈值（没有则留空）：
- 输出文件位置：
- 人工审核反馈与已确认规则：

未提供的数据留空；产品参数以用户资料为准。不要填写示例 ASIN 作为真实竞品。
