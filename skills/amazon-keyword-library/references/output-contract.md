# 字段和工作簿规范

## 总词库

基础字段：关键词、关键词原文、关键词中文翻译、关键词搜索频率排名ABA、月度搜索量、PPC、购买率、SPR。

审计字段：去重键、站点、数据周期、来源文件/工作表/行号、指标来源、采集时间、币种、指标口径、数据冲突、缺失原因。

决策字段：主类别、辅助标签、是否长尾、相关性、分类理由、否定原因、用途建议、广告优先级、优先级依据、审核状态、人工反馈。

主类别为八类之一：核心词、属性词、功能词、场景词、材质词、扩展词、待复核词、否定词。材质也可以在属性分表中出现。长尾按意图具体程度和属性组合判断，不能只用固定词数。用途和优先级是建议，不代表执行授权。

数值保持数值类型；缺失使用空单元格，不填 0 或估算值。百分比统一显示，但必须先确认源数据是 0–1 还是 0–100；未知时保留原值并标记。PPC 的具体含义（建议竞价、实测 CPC 等）及 SPR 的供应商定义应记录，不推断通用定义。低 ABA 数字表示更靠前的排名，不等于更高转化。

同一指标有多个周期时，使用明确周期的字段或独立指标明细表；每个指标都应可追溯到来源，不只标整行来源。完全无关的词从运营候选分表排除，但总词库保留审计记录。

## 必需 Sheets

| Sheet | 内容 |
| --- | --- |
| 01_总词库 | 所有有效去重关键词、指标、来源、分类及审核状态 |
| 02_核心词 | 产品核心意图词，辅助 Listing 与核心广告选词 |
| 03_属性功能词 | 属性、功能及材质相关词 |
| 04_场景词 | 使用场景相关词 |
| 05_长尾机会词 | 长尾词及机会依据；证据不足注明待验证 |
| 06_否定词 | 候选及已确认否词，必须含原因和审核状态 |
| 07_待复核 | 歧义、边界未知、分类分歧和重要决策疑点 |
| 08_质量报告 | 输入数量、空关键词、重复数量、冲突、缺失、各类别数量、校验结果 |
| 09_项目边界 | 本次输入卡、分类规则、指标口径和人工修订记录 |

扩展词保留在总词库并使用标签；需要时新增扩展词、指标明细或冲突明细 Sheet。可以在场景或长尾表中同时出现。没有记录的 Sheet 仍保留表头。

审核状态：待审核、已确认、需修改。数据状态与审核状态分别记录；不能把“查到指标”等同于“运营人员确认”。

## 交付检查

- 源文件未被覆盖，成品可重新读取。
- 每个站点的规范化英文关键词唯一，跨站点不会混用指标。
- 每条记录及每个指标有可追溯来源；冲突明确展示。
- 缺失数值仍为空，文本不会变成意外公式。
- 否词候选均有产品边界依据，不因缺少核心单词而否定。
- 未审核结论明确标为草稿，分表与总表内容一致。
- 不同分表允许重叠，质量报告说明统计口径。
